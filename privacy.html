Privacy Policy

Effective date: November 19, 2026

This policy describes the personal-use BijanRadTeaching Archive workflow. Questions can be sent to mfot2386@gmail.com.

Information processed

When the account owner uses the workflow, it may process files the owner places in designated Google Drive folders, including WhatsApp chat-export ZIP files, chat text, photos, PDFs, videos, audio, other attachments, and archive support files such as HTML and JSON. The workflow may also process file names, identifiers, timestamps, and operational information needed to detect and update files.

How information is used

The information is used only to build and maintain the owner's personal chat archive, including its searchable HTML viewer and associated media. The owner must manually export each WhatsApp chat using WhatsApp's own export feature and upload the export to the designated Google Drive Incoming folder. This workflow does not access WhatsApp directly or automatically export messages.

Google Drive and GitHub processing

With the owner's Google authorization, the workflow reads files from the designated Google Drive folders and writes the updated archive and media back to the owner's Drive. During a scheduled or manually started run, the files are processed on a GitHub-hosted Actions runner. GitHub therefore acts as a service provider involved in running the workflow. The source-code repository is intended to contain code and configuration only, not chat exports, archive content, media, or OAuth tokens.

OAuth authorization is used to access Google Drive. Access tokens and related credentials should be stored only in the repository's protected GitHub Actions secrets and should never be placed in source code, public files, workflow logs, or messages. Google and GitHub process information under their own terms and privacy policies.

Sharing, sale, and retention

This personal-use workflow is not designed to sell chat content or use it for advertising. The archive and its media remain in the owner's Google Drive, where the owner controls retention and deletion. GitHub may retain workflow run metadata and logs according to GitHub's policies. The workflow should avoid logging message contents or attachment contents.

Choices and access revocation

The owner can stop processing by disabling the GitHub Actions workflow, remove stored workflow secrets from the repository settings, revoke the app's Google access through the Google Account third-party connections page, and delete archive or incoming files from Google Drive.

Sensitive information

This utility is not represented as HIPAA-compliant and is not a healthcare service or business associate. Chat exports may contain sensitive personal or medical information. The owner is responsible for deciding whether uploading and processing such information is lawful and appropriate. Avoid including identifiable patient information unless all applicable requirements have been independently satisfied.

Changes

This policy may be updated if the workflow's data handling changes. The effective date above will be revised when material changes are made.
