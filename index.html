BijanRadTeaching Archive

This is a personal-use workflow for maintaining a searchable archive of a WhatsApp group chat and its exported attachments.

How it works

  1. The account owner manually exports the group chat using WhatsApp's built-in Export Chat feature.
  2. The owner places the exported ZIP file in the designated Incoming folder in their own Google Drive.
  3. A scheduled GitHub Actions workflow accesses the designated Drive folders with the owner's authorization, processes new exports, and updates the archive and media files in the owner's Google Drive.

The workflow does not connect directly to WhatsApp, read WhatsApp messages automatically, or use an official WhatsApp API to export chats. A new export must be made manually by the account owner.

Data and security

The archive is stored in the owner's Google Drive. During an update, the export and relevant archive files are processed by a temporary GitHub-hosted Actions runner. The workflow is designed not to commit chat content, attachments, or OAuth credentials to this website or the updater's source-code repository.
